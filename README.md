# homebrew-tap

Homebrew formulae for the open source Kubernetes cost CLIs by Roberta Soliman.

```sh
brew tap robertasolimandonofreo/tap
brew install spot-readiness
brew install graviton-readiness
brew install rightsizing-check
```

| Formula | What it does |
| --- | --- |
| [spot-readiness](https://github.com/robertasolimandonofreo/spot-readiness) | Finds which Kubernetes workloads can safely run on Spot |
| [graviton-readiness](https://github.com/robertasolimandonofreo/graviton-readiness) | Finds which workloads can run on Graviton (arm64) nodes |
| [rightsizing-check](https://github.com/robertasolimandonofreo/rightsizing-check) | Finds CPU and memory requests far above real usage |

The formulae in `Formula/` are generated by GoReleaser on each release of the tools above. Do not edit them by hand.

Guides and articles: https://www.robertasoliman.com/en/tools/
